When variation in the resource landscape is spatiotemporally predictable, memory plays a crucial role in facilitating an animal’s successful adaptation to altered resource conditions. 


To better understand how supplementary feeding alters local resource distributions and reshapes animal movement, I incorporate memory into the integrated step selection function (iSSF) framework. This approach allows me to examine the interaction between memory of feeding sites and baseline landscape familiarity, providing an opportunity to assess how the location of bait within an individual’s home range influences movement behavior.
